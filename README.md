# LaunchHome Homebrew Tap

[LaunchHome](https://launchhome.app/) is a Launchpad replacement for macOS 26 Tahoe and macOS 27. Apple removed Launchpad in macOS 26; LaunchHome brings back the full-screen app grid with pages, folders and drag-and-drop arranging, opened with F4, a hot corner or a trackpad pinch.

## Install

```bash
brew install --cask userand/tap/launchhome
```

The app is signed and notarized by Apple and updates itself (Sparkle), so `brew upgrade` is not needed.

## Uninstall

```bash
brew uninstall --cask launchhome
```

Add `--zap` to also remove your layout, settings and license data.
